# LanguageTrainer

![Status: experimental](https://img.shields.io/badge/status-experimental-yellow)
![Version: 0.4.2](https://img.shields.io/badge/version-0.4.2-blue)

A desktop app for learning vocabulary through typing and reading. Practise words and definitions, read books, save quotations, and revisit difficult material with spaced repetition.

Dictionary lookups, pronunciation, and optional English-to-Russian translation work locally. Each user has their own progress and collections, with *Zen* and *Thinking, Fast and Slow* included as starter books.

## Windows

Extract the portable ZIP and open `LanguageTrainer.exe`. No separate Python installation is needed. Keep the `data` folder when upgrading.

Version 0.4.2 is experimental; the updated Windows package is being tested.
